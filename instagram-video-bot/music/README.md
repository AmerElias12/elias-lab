# Background music

Drop audio files here (`.mp3`, `.m4a`, `.aac`, `.wav`, `.ogg`, `.flac`). Each
day's Reel uses one: the newest file nobody has used yet, or otherwise the one
used longest ago. To follow a trend, add the track this week and it goes out
next.

Only use tracks you have the rights to post. Instagram mutes or removes Reels
with unlicensed audio. The API also can't attach songs from Instagram's own
music library. Free sources include the YouTube Audio Library and Pixabay
Music, and you can buy licences from Epidemic Sound or Artlist.

The audio files are git-ignored, because this repository is public.
