LAB MEMBER PHOTOS — put them here
=================================

1. Save each person's picture in THIS folder (assets/team/).

2. Name the file after the person, all lowercase, with a dash instead
   of a space:

       amer-elias.jpg
       sarah-cohen.jpg
       mohammed-khoury.jpg

   .jpg and .png both work.

3. Then open  js/team-data.js  and write that same file name on the
   "photo:" line for that person. That's the only link between the two.

If a photo is missing or the name doesn't match, the site shows the
person's initials in a coloured circle instead — it never looks broken.


WHAT KIND OF PHOTO WORKS BEST
-----------------------------
- Square, or close to it. The site crops to a circle, cropping from the
  centre, so anything very wide or very tall loses the edges.
- Face roughly centred.
- At least 400 x 400 pixels (bigger is fine — 800 x 800 is ideal).
- Plain or blurred background looks best next to the other cards.

A phone portrait photo is perfectly good. If a photo comes out cropped
awkwardly, say so and it can be adjusted.


LINKEDIN LINKS
--------------
Those do NOT go here — they go in  js/team-data.js  on the
"linkedin:" line, as the full address:

    linkedin: "https://www.linkedin.com/in/sarah-cohen-1a2b3c/"

To copy it: open the person's LinkedIn profile in a browser and copy the
whole address from the address bar.
